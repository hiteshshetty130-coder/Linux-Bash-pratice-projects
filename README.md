### 2. Major Project – Application Log Monitoring System

A Bash-based application log monitoring system designed to monitor application logs, identify important events, and generate alerts and reports automatically.

**Key Features:**
- Monitors application log files.
- Detects new log entries using checkpoint-based tracking.
- Identifies important log events and generates alerts.
- Generates monitoring summaries.
- Handles log truncation and rotation scenarios.
- Uses checkpoint management to avoid unnecessary reprocessing.
- Supports automated execution using Cron.
- Includes error handling and execution logging.

**Technologies Used:**
- Linux (Ubuntu)
- Bash Shell Scripting
- Linux Commands and Utilities
- Cron Jobs
- File and Process Management
